# Archived Scripts

These are historical one-off utility scripts used during the initial build of the WWE Database. They have already been run and their results are incorporated into the app's data files. They are kept here for project history but are not needed for development.

## Categories

- **cleanup/** - Name formatting and parenthetical cleanup scripts
- **dedup/** - Duplicate entry removal scripts
- **reigns/** - Championship reign date population scripts
- **images/** - WWE.com and Wikipedia image fetching/injection scripts
- **ids/** - RELATIONSHIPS ID mismatch fixing scripts
- **data/** - Intermediate JSON/TXT artifacts from the scripts above
- **backups/** - Old full-file backups from before the refactor
